# Jaipur Cricket Circle

A modern community cricket website for Jaipur Cricket Circle.

## Features

- Sunday match registration
- Admin approval for new members
- Existing member quick registration
- Match control dashboard
- Captain and vice-captain assignment
- Chewvana Times article CMS
- Members directory
- WhatsApp contact integration

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
